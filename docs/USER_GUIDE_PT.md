## Primeiros Passos

### Criando uma Conta de Jogador

1. Abra https://spinsheets.com
2. Selecione **Get Started** para abrir o formulário de registro
3. Insira um nome de usuário, email e senha
4. Você será logado automaticamente como **Jogador**

Como Jogador você pode:
- Criar personagens para qualquer um dos 8 sistemas de jogo suportados
- Entrar em crônicas que Narradores criaram
- Usar roladores de dados integrados, catálogos e rastreamento de XP
- Exportar suas fichas de personagem como PDF

### Tornando-se um Narrador

Se você conduz jogos, peça ao administrador do seu grupo para promover sua conta para **Narrador**. Essa role oferece ferramentas adicionais:

- **Geradores de NPC** — Acesse mais de 350 templates de antagonistas prontos em todos os sistemas
- **Gerenciamento de Crônicas** — Crie e gerencie campanhas de jogo, convide jogadores, registre sessões
- **Acesso às Fichas dos Jogadores** — Visualize e edite as fichas dos seus jogadores
- **Mecânicas de Relógio** — Acompanhe progresso, perigo e relógios de facção (Blades in the Dark)
- **Notas de Sessão** — Registre resumos de sessão dentro de cada crônica

## Guia do Jogador

### Criando um Personagem

1. Abra a página de **Personagens** no menu de navegação
2. Selecione **Novo Personagem**
3. Escolha seu sistema de jogo (World of Darkness, 7th Sea, L5R, Blades, D&D, UESTRPG ou Cyberpunk)
4. Escolha **Para Mim** (livre) ou **Para uma Crônica** (vinculado ao jogo de um Narrador)
5. Para World of Darkness, você escolherá uma linha de jogo específica (Vampire, Werewolf, Mage, etc.)
6. Sua ficha de personagem abre com abas para todas as seções relevantes

### Trabalhando com Abas

Cada ficha de personagem é organizada em abas. Abas comuns entre sistemas:

| Aba | O Que Contém |
|-----|--------------|
| **Identidade** | Nome, conceito, histórico, aparência |
| **Atributos/Stats** | Estatísticas principais do seu sistema |
| **Habilidades/Perícias** | Pontuações de habilidades e especialidades |
| **Poderes** | Disciplinas, Dons, Magias, Cyberware — varia por sistema |
| **Combate** | Armadura, armas, rastreamento de ferimentos, saúde |
| **Equipamento** | Inventário, moeda, itens |
| **Backstory** | Texto livre para histórico e notas |
| **Log de XP** | Rastreamento de pontos de experiência com cálculos de custo |
| **Rolador de Dados** | Rolador integrado para a mecânica do seu sistema |
| **Referência de Regras** | Referência rápida para regras comuns |

### Usando Catálogos

Ao invés de folhear livros de regras, use os catálogos pesquisáveis integrados:

1. Encontre um dropdown de catálogo (rotulado "Adicionar Disciplina", "Adicionar Magia", etc.)
2. Comece a digitar para filtrar por nome
3. Cada entrada mostra uma descrição — leia para confirmar que é o que você quer
4. Selecione uma entrada para adicioná-la à sua ficha
5. Para habilidades com pontuação (como Disciplinas ou Habilidades), ajuste a pontuação de pontos após adicionar

Catálogos estão disponíveis para:
- **WoD:** Disciplinas, Dons, Ritos, Rotes, Esferas, Qualidades, Defeitos, Antecedentes, Arcanoi, Edges, Lores, Artes, Reinos
- **7th Sea:** Vantagens, Feitiçarias, Estilos de Duelo
- **L5R:** Escolas, Magias, Kata, Vantagens, Desvantagens, Equipamento
- **Blades:** Playbooks, Habilidades, Itens, Contatos, Tipos de Crew
- **D&D:** Classes, Raças, Magias (233), Talentos (42), Equipamento, Monstros (120)
- **UESTRPG:** Raças, Classes, Constelações, Equipamento (temática TES)
- **Cyberpunk:** Roles, Cyberware (150+), Armas (58), Armaduras (24), Equipamento (52), Veículos (38)

### Salvando Seu Trabalho

- **Salvar Rápido** — Salva seu progresso atual sem sair da página
- **Concluir Edição** — Salva e retorna à lista de personagens
- Seus dados são armazenados no servidor — você pode acessá-los de qualquer dispositivo

### Buscando e Filtrando Personagens

A página de **Personagens** oferece diversas ferramentas:

- **Abas de filtro por sistema** — Mostra apenas personagens de um sistema de jogo específico
- **Busca** — Digite um nome para filtrar instantaneamente
- **Ordenar** — Alterne entre Mais Recente, Mais Antigo ou A-Z
- **Filtro PC/NPC** — Mostra Todos, apenas PCs ou apenas NPCs

## Guia do Narrador

### Gerenciando Crônicas

1. Abra a página de **Crônicas** no menu de navegação
2. Selecione **Criar Crônica**
3. Escolha o sistema de jogo para esta crônica
4. Insira um nome e descrição
5. Sua crônica está criada — agora você pode convidar jogadores

### Convidando Jogadores

1. Abra a página de detalhes de uma crônica
2. Gere um link de convite
3. Compartilhe o link com seus jogadores
4. Jogadores que seguirem o link podem criar um personagem vinculado à sua crônica

### Geradores de NPC

Como Narrador, você tem acesso a geradores de NPC/Antagonista para cada sistema:

1. Vá para a página de lista de personagens de qualquer sistema
2. Selecione **Novo Antagonista** ou **Novo NPC**
3. Use o dropdown de template para carregar um NPC pronto
4. Customize stats, equipamento e notas conforme necessário
5. Salve o NPC — ele aparece na sua lista de personagens marcado como NPC

**Templates prontos incluem:**
- **WoD:** 122 NPCs (Mortais, Vampiros, Lobisomens, Magos, Caçadores, Wraiths, Changelings, Demônios, Carniçais, Familiares, Totens)
- **7th Sea:** 35 NPCs (Vilões, Heróis, Capangas, Esquadrões de Brutos, Monstros)
- **L5R:** 37 NPCs (Samurais por clã, Bandidos, Oni, Maho-Tsukai, Antagonistas Políticos)
- **Blades:** 23 NPCs (Capangas de rua até Lord Scurlock)
- **D&D:** 120 Monstros (CR 0 até CR 24)
- **UESTRPG:** 34 NPCs (Bandidos até Dragões)
- **Cyberpunk:** 25 NPCs (Boostergang até Operativos da Arasaka)

### Mecânicas de Relógio (Blades in the Dark)

Narradores têm acesso a um **Gerenciador de Relógios** dedicado para Blades:

1. Vá para a página de lista de personagens de Blades
2. Selecione **Gerenciador de Relógios**
3. Crie relógios com 4, 6, 8 ou 12 segmentos
4. Atribua um tipo: Progresso, Perigo, Corrida, Facção, Projeto de Longo Prazo ou Customizado
5. Agrupe relógios por sessão ou tema
6. Selecione segmentos para preenchê-los/esvaziá-los
7. Filtre por tipo ou grupo
8. Limpe relógios completos quando terminados

Relógios também estão disponíveis como aba em fichas individuais de personagem e crew de Blades.

### Visualizando Fichas dos Jogadores

Como Narrador:
- Todos os personagens dos jogadores aparecem na sua página de Personagens
- Cada card de personagem mostra o nome de usuário do jogador
- Você pode visualizar e editar a ficha de qualquer jogador
- Use a página de detalhes da crônica para ver todos os personagens vinculados a uma crônica específica

### World of Darkness (WoD)

**Linhas de jogo suportadas:**
- Vampire: The Masquerade (V20, Revised, Dark Ages, Victorian Age)
- Kindred of the East
- Werewolf: The Apocalypse (W20, Wyld West)
- Changing Breeds / Fera
- Mage: The Ascension (M20, Victorian Mage)
- Hunter: The Reckoning
- Wraith: The Oblivion
- Changeling: The Dreaming
- Demon: The Fallen

**Sistema de dados:** pool de d10 (Storyteller System)
**Rastreamento de XP:** Pontos de experiência com orçamentos de pontos de bônus

### 7th Sea (2a Edição)

**Funcionalidades:** Fichas de Herói e Vilão, Construtor de Navio, 8 Feitiçarias, Estilos de Duelo
**Sistema de dados:** conjuntos de d10 (Raises)
**Rastreamento de XP:** Pontos de experiência

### Legend of the Five Rings (4a Edição)

**Funcionalidades:** 55 Escolas em 9 Clãs, 197 Magias, 26 Kata, Maestrias de Habilidade
**Sistema de dados:** Roll-and-keep (k-dice)
**Rastreamento de XP:** Pontos de experiência com cálculo de rank de insight

### Blades in the Dark

**Funcionalidades:** 11 Playbooks, 6 Tipos de Crew, toggle de Deep Cuts, Gerenciador de Relógios, rastreamento de Estresse/Trauma
**Sistema de dados:** pool de d6
**Rastreamento de XP:** Pips de XP do Playbook

### D&D 5a Edição

**Funcionalidades:** 13 Classes, 9 Raças, 233 Magias, 42 Talentos, 120 templates de Monstros, Catálogo de Equipamento
**Sistema de dados:** d20
**Rastreamento de XP:** Baseado em nível com log de XP opcional

### UESTRPG (Unofficial Elder Scrolls RPG)

**Funcionalidades:** 10 Raças TES, 13 Classes, 13 Constelações, sistema de Magicka, equipamento com temática TES
**Sistema de dados:** d20 (conversão de D&D 5e)
**Rastreamento de XP:** Baseado em nível

### Cyberpunk 2020

**Funcionalidades:** 10 Roles, 60+ Habilidades, 150+ Cyberware, 58 Armas, 38 Veículos, gerador de Lifepath, rastreamento de Humanidade
**Sistema de dados:** d10 (STAT + Habilidade + d10)
**Rastreamento de XP:** Pontos de Aprimoramento (IP)

## Roladores de Dados

Cada sistema possui um rolador de dados dedicado acessível pela aba Rolador de Dados:

| Sistema | Rolador | Mecânica |
|---------|---------|----------|
| WoD | Pool de d10 | Role X d10s, conte sucessos (8+), 1s subtraem |
| 7th Sea | Conjuntos de d10 | Role X d10s, forme conjuntos de 10 para Raises |
| L5R | Roll-and-Keep | Role X d10s, mantenha os Y maiores, 10s explodem |
| Blades | Pool de d6 | Role X d6s, pegue o maior (6=sucesso total, 4-5=parcial, 1-3=ruim) |
| D&D / UESTRPG | d20 | d20 + modificador vs. CD, vantagem/desvantagem |
| Cyberpunk | d10 | STAT + Habilidade + d10, falha crítica no 1, crítico no 10 (explode) |

Todos os roladores incluem:
- Histórico de rolagens (últimas 10+ rolagens)
- Campos de modificadores
- Interpretação de resultado
- Roladores de dano/secundários quando aplicável

## Exportação e Impressão

### Exportar PDF (Seções Seletivas)

1. Abra qualquer ficha de personagem
2. Selecione o botão **Exportar PDF** na barra de ações
3. Um diálogo abre mostrando todas as abas como checkboxes
4. Desmarque seções que deseja excluir (Rolador de Dados, Log de XP, etc.)
5. Selecione **Imprimir / Salvar como PDF**
6. O diálogo de impressão do seu navegador abre com apenas as seções selecionadas visíveis
7. Escolha "Salvar como PDF" no diálogo de impressão para criar um arquivo PDF

### Impressão Rápida (Todas as Seções)

Pressione **Ctrl+P** (Windows/Linux) ou **Cmd+P** (Mac) em qualquer ficha de personagem. A folha de estilo de impressão automaticamente:
- Mostra todos os painéis de aba (não apenas a aba ativa)
- Esconde navegação, botões e modais
- Usa um layout limpo preto-no-branco
- Aplica regras de quebra de página para prevenir seções divididas

## Gerenciamento de Conta

### Alterando Sua Senha

1. Faça logout
2. Na página de login, selecione "Esqueci a Senha"
3. Insira seu endereço de email
4. Verifique seu email para um link de reset
5. Siga o link para definir uma nova senha

### Trocando o Idioma

O toggle de idioma está sempre visível no header. Ele mostra:
- **"Mudar Idioma"** quando visualizando em Inglês (trocar para Português)
- **"Switch Language"** quando visualizando em Português (trocar para Inglês)

### Excluindo Sua Conta

Disponível no seu menu de usuário. Isso exclui permanentemente sua conta e todos os personagens associados.

## Solução de Problemas

### "Falha ao carregar personagens"

- **Limpe o cache do navegador** — especialmente no mobile, JavaScript em cache desatualizado pode causar erros
- **Verifique sua conexão com a internet** — o site requer conexão para carregar dados
- **Tente fazer logout e login novamente** — seu token de sessão pode ter expirado

### Ficha de personagem não carrega

- **Tente atualizar a página** — o sistema `lazyRetry` vai automaticamente recarregar se os arquivos de chunk estiverem desatualizados
- **Limpe o cache do navegador** se atualizar não ajudar

### Problemas de layout no mobile

- **Evite diminuir o zoom** — o site é projetado para zoom de 100%
- **Use o menu hamburger** — a navegação colapsa em um menu em telas pequenas
- **Gire para paisagem** para fichas complexas se necessário

### Impressão/Exportação mostra conteúdo errado

- Certifique-se de usar **Exportar PDF** (não Ctrl+P) se quiser selecionar seções específicas
- Se seções estiverem faltando, verifique se os checkboxes estão marcados no diálogo de exportação
